<h1 align="center">Buscador</h1>

## Descripción
El programa recibe una carpeta, proporcionada por el usuario, y busca la palabra 'home' en todos los archivos dentro de la carpeta y sus subcarpetas.
## Uso
```bash
./buscar.sh carpeta   #Introduce el nombre de la carpeta en dónde quieres buscar '(tu variable)'
```
## Validación
1. Si la palabra existe dentro de los archivos, mostrará la ruta
2. Si la carpeta no es válida el programa dará error
3. Si ningún archivo contiene la palabra "home" el programa te lo hará saber
